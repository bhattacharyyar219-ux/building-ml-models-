# 🤖 Machine Learning From Scratch

A hands-on machine learning repository focused on **implementing machine learning algorithms from scratch** to understand their mathematical foundations, optimization techniques, and underlying mechanics.

Instead of relying entirely on high-level libraries, this project aims to build algorithms step by step using **Python, NumPy, and mathematical concepts**, making it easier to understand what happens behind the scenes.

## 🚀 Algorithms

### Currently Implemented
- 📈 **Linear Regression**
  - Cost function
  - Gradient descent

  - Prediction
  - Evaluation

- 🔢 **Logistic Regression**

## 🧠 Learning Goals

This repository is built to develop a strong understanding of:

- Reinforcement learning

## 📊 Approach

Each algorithm is implemented with an emphasis on understanding **how and why it works**, rather than simply using a pre-built implementation.

The general workflow is:

```text
Mathematical Concept
        ↓
Algorithm Derivation
        ↓
From-Scratch Implementation
        ↓
Training & Optimization
        ↓
Testing & Evaluation
        ↓
Comparison with Standard Libraries
```

## 🎯 Purpose

The goal of this repository is to create a growing collection of **machine learning algorithms built from the ground up**, serving as both a learning resource and a practical reference for understanding ML beyond library-level usage.

> **Learn the mathematics. Understand the algorithm. Build it from scratch.**
